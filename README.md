## ✨ Features

* **Responsive Design:** A clean, mobile-first design that looks great on any device, from phones to desktops.
* **Cross Out:** Allows the user to click on a task they've completed to cross of the to-do list
* **Clear All or Clear Completed:** Allows the user to remove either completed tasks from the list or clear the list entirely.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Core Concepts:** DOM Manipulation, Advanced Event Handling (Event Delegation), and Client-Side State Management.
* **Deployment:** Git Pages
